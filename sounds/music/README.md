# Músicas de encerramento

Coloque os arquivos abaixo nesta pasta, com estes nomes exatos:

- `victory.mp3` — toca uma vez na tela de vitória.
- `game-over.mp3` — toca uma vez na tela de derrota.

Essas duas faixas ficam fora da playlist comum. Elas usam o volume e a preferência de música do menu global. Depois de adicionar os arquivos, recarregue o jogo para atualizar o catálogo de músicas.
